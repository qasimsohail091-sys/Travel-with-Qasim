# Travel With Qasim

Travel With Qasim is a travel website designed to provide users with information about different travel destinations.

## Pages

- Home
- About
- Destinations
- Gallery
- Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation menu to explore the website.
